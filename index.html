55 episodes under one configuration, checked by tools/config_audit.py before any of them ran. Every episode was run twice — once seeing only pixels, once with a structured readout of the kitchen — and both are shown, scored and transcribed. Runs the harness cut off before a verdict are marked undetermined, never counted as failures. One run per cell except where repeats are stated, so differences are observations rather than effect estimates.
