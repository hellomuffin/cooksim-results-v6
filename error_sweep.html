Error types × timing

Every error type the engine can inject, at more than one point in the plan, on more than one recipe, against both cooks. Each card says whether the injection actually fired and whether the cook actually committed the error — the two things a score hides. Error commission is read from the engine's own plating order, not from the compliance flag, which is a set-membership test and cannot see order at all.
