Suite v3 results — the new number axis

This page introduces the assistant benchmark's numbers on the new suite. The three tables in §1 put the same assistants on three axes so the change can be read left to right: the original v2.2 suite under the old 480-tick "human pace" (the 2026-08 sweep), the same suite under the tight fire timers, and suite v3 (2/2/3/4/4 forced errors per episode with at least half of them dish-ruining, content-hard questions, proactive alerts) under the tight timers. All rows are the average-person cook (questionnaire 2·2·2); the suite-v3 sweep runs in the frames setting only (the assistant sees the rendered kitchen, never a text state map), and the SILENT floor — which sees nothing either way — comes from the text-mode run of the same root. Per-persona tables follow once the sweep has filled in. Metrics are evaluation v3 with the 2026-08-27 rulings: in-time success = 1 only if the dish was won within 2 × (reference + allowance) ticks; DT = prevented 1 / correct flag before commit 0.5 / else 0; P, R, F1 over forced errors with a late flag counted as a miss; assistance quality v3 = (b·(DT+F1) + 2·SQ)/(2b+2); QA accuracy = judge-graded answers (correct 1, partially correct 0.5); proactive score = 1 at the moment the item is done, falling to 0 at the end of its ready window, 0 if spoken early, late or never. Rows fill in as the pilot runs; a full sweep replaces them once authorised.
