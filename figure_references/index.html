For the current Figure 1 replacement. TEACh is the closest structural match; Collaborative Gym remains the conversation-style reference. The key difference in our figure: the human acts, while the assistant observes and communicates.

Recommended combinationCollaborative Gym’s selective dialogue + TEACh’s action-linked visual progression + DialFRED’s explicit correspondence between conversation, action, and observation. The nested assistant/persona comparison is our own composition.

The hierarchy to preserve in our teaser

Shared task and error onset · RGB checkpoint ├─ Assistant A · early warning → user changes action → error prevented ├─ Assistant B · warning after the point of no return │ ├─ High trust + wants step-by-step guidance → dialogue → action → recovery RGB │ └─ Low trust + dislikes interruption → different dialogue → different action path └─ Assistant C · silence → user continues → error consequence

Only the late-recognition branch expands into two user trajectories. Mark the point of no return at the engine-defined irreversible step; show a recovery checkpoint immediately after discard if that is the chosen event. Low trust does not automatically imply failure.

This is a content hierarchy, not a committed layout. A top-level three-way comparison with the middle case expanded below may read better than a wide branching tree.

Select images by information gain.Each environment image should reveal a different object, interaction, or state change. Avoid repeated stove views or nearly identical Settings pages.

Keep the causal unit visible.Pair a short exchange with the action it changes and the resulting RGB state. Use images at decisive moments, not at every utterance.

Separate illustration from evidence.Any authored dialogue will be labeled illustrative. Before drafting, verify the chosen task, irreversible error, and recovery against the current engine.
