How it runs

  • Orchestrator: tools/rerun_v6/orchestrate.py daemon; state tmp/rerun_v6/state.json; logs tmp/rerun_v6/logs/.
  • API seat: run_assist_bench.py --tag <seat> --paradigm hardsoft --persona-v2 baseline classic_novice classic_expert --workers 3–4, resume-safe; a process that exits early is relaunched up to 3 times.
  • GPU seat: beaker_submit.py bench <seat> --replicas 5 --cluster <jupiter | saturn for the cook swap>; a seat whose experiment finalised or wrote nothing for 4 h with episodes missing is resubmitted (resume-safe) up to 3 times.
  • Verifier: tools/rerun_v6/verify_phase.py <phase> — presence, engine stamp, outcomes, fired events, assistant speech, latency mode.
  • Scoring per phase root: eval_v2_sweep.py (objective), regrade_qa.py (questions), sq_v4_score.py --judge gpt-main (rubric).
